# El viaje de Semi 🌱

Complemento didáctico interactivo (≈10 minutos) para Educación Infantil, 5 años: Semi, una pepita de manzana, guía a los niños por el ciclo de vida de las plantas.

**Recorrido:** la semilla despierta con la lluvia → las raíces buscan agua → partes de la planta → cómo come (sol, agua, aire, tierra) → el tiempo y el clima → de plantita a manzano → la abeja poliniza las flores → la flor se convierte en manzana y se plantan sus pepitas → ¿qué fruto da cada planta? → el ciclo de la vida → juego final.

- Landing para el profesorado con el botón «Empezar gratis».
- Voz narradora (Carlota, ElevenLabs) en `audio/`; las frases sin grabar usan la voz del navegador.
- Funciona con dedo y ratón: pizarra digital, tablet u ordenador.

Web estática: `index.html` + `audio/`. Sin compilación; se despliega tal cual en Vercel.
